自分用のMIDIビジュアライザーなどの詰め合わせです。

自分用なのでデプロイはしていません。

使用ライブラリはmido、pygameです。おそらくPython3系なら動きます。


使い道としては曲のMVや楽器の練習動画などを想定してます。

各種パラメータはハードコードされてるので直接プログラムを編集してください。

出力される動画は仕様上透過できなかったので、ご自身の編集ソフトのクロマキー機能を使ってください。背景色自体は変更可能です。

説明
- midi_visualizer.py
  
  シンプルな鍵盤のビジュアライザーです。MIDIと出力先のフォルダを指定すれば動きます。

  実装はOpenCVとPyGameです。
  
- midi_visualizer_moviepy.py
  
  上のものに加えて、黒鍵と白鍵の代わりに任意の画像や動画を読み込めます。透過のものはそのまま透過して重ねて表示されます。
  
  位置も自由に調整できるので表現の幅は意外と大きいです。これの出力を複数重ねてもいいかも
  
  実装方法がmoviePyなのでこの名前です。
